# MLHealth360 Chest CT Scan Research

This repository contains the research and development work for the **MLHealth360 Chest CT Scan Project**.

The primary objective of this project is to develop and evaluate a **segmentation and preprocessing pipeline for Chest CT scans** that can later be used for deep learning and medical image analysis tasks.

## Project Objectives

The project will focus on:

- Understanding and preparing Chest CT scan datasets.
- Developing preprocessing pipelines for CT volumes.
- Developing segmentation pipelines for regions and abnormalities of interest.
- Evaluating preprocessing and segmentation techniques using appropriate quantitative metrics.
- Preparing processed data for deep learning model development.
- Comparing different approaches and documenting experimental results.
